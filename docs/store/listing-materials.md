彩云笔记是一款本地优先的云端笔记应用。

- 页面、页签常态化保存本地副本，打开应用即是上次内容
- 断网、弱网下继续记录，连接恢复后自动同步

- 笔记本 → 分区 → 页面 → 页签，熟悉的层级

【实时协作】
- 多人编辑自动合并，共享权限与页面锁划定清晰边界
- 同事实时看到更新，互不打扰

【一个空间，更多工作】
- 邮箱笔记：把有价值的邮件留在笔记里
- 行程规划：内嵌地图、路线与时间安排
- AI 助手：语音转写与内容整理（自行配置大模型服务）
- 网盘附件：OneDrive、百度网盘、七牛云、AnyShare
